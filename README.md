# Python for Digital Geoscience 🌍

Welcome to my learning portfolio!

This repository contains my Python practice and projects as I explore the application of programming and data analysis to geoscience.

With a background in geology and ongoing postgraduate studies in exploration geophysics, I'm developing my programming skills to support subsurface data analysis and geoscientific workflows, building my Python programming and data analysis skills to explore the intersection of geoscience, technology, and data-driven decision-making.

The repository documents my learning journey, practical exercises, and projects as I develop the skills to apply programming to real-world geoscience problems. It covers Python fundamentals, well-log analysis, basic statistical analysis, and other practical applications as I progress.

## Learning Objectives

- Build a strong foundation in Python programming.
- Develop skills in data analysis, manipulation, and visualisation.
- Explore practical applications of Python in geoscience and subsurface data analysis.
- Gradually develop reproducible workflows for well-log analysis and petrophysical evaluation.

## Repository Contents

As I progress, this repository will include:

- **Python Fundamentals:** Variables, data types, conditional statements, loops, functions, and lists.
- **Well-Log Analysis:** Gamma-ray interpretation, porosity calculations, and interval flagging.
- **Geoscience Data Analysis:** Data quality checks, statistical summaries, and visualisation.
- **Projects:** Practical, documented projects applying Python to geoscience problems.
